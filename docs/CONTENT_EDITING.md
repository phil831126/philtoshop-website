# 內容更新教學：上傳照片、新增作品、首頁精選

> 文字怎麼改、怎麼加超連結，見 [EDIT_TEXT.md](EDIT_TEXT.md)。

## 最短流程（替換或增加照片）

1. 把照片放進對應資料夾：`public/images/works/<分類>/<作品資料夾>/`
2. 執行 `npm.cmd run dev` 預覽（已經開著的話會**自動更新**，不用重開）
3. 推送上線：`git add .` → `git commit -m "Update photos"` → `git push`

**不需要修改任何程式。** 照片會自動依**檔名順序**排列，寬高自動讀取，照片數（例如 10 PHOTOS）自動計算。

---

## 重要提醒

- **「顯示：否」只是讓網站不顯示，不是隱私保護。** 放在 `public/` 的照片推送後，任何知道網址的人都能開啟；儲存庫若為 Public，所有檔案也都看得到。**私密原始照片不要放進專案。**
- **照片會自動縮小**：`npm.cmd run dev` 開著時，放進資料夾的照片如果是 PNG、長邊超過 2000 px 或超過 500 KB，會自動轉成 JPG 並縮小（檔名不變，副檔名變成 `.jpg`），同時移除 GPS 拍攝地點。沒開 dev 的話，推送前執行一次 `npm.cmd run photos` 也會處理。
- 自動縮小會**直接取代**專案裡的檔案，原始大圖請另外保存在自己的電腦或雲端。
- 用手機或相機原檔也沒關係，不需要自己先縮圖。
- 檔名建議用 **小寫英文、數字、連字號**，例如 `01.jpg`。大寫或空白也能顯示，但工具會提醒你。

## 照片的排列與顯示

| 想做什麼 | 怎麼做 |
| --- | --- |
| 調整照片順序 | **改檔名**：`01.jpg` 會排在 `02.jpg` 前面（`10.jpg` 也會正確排在 `09.jpg` 後面） |
| 暫時不顯示某張照片 | 在檔名前面加底線，例如 `_05.jpg`（檔案仍在公開資料夾中） |
| 刪除照片 | 直接刪除檔案 |
| 換照片 | 用同檔名覆蓋 |

顯示方式：

- 分類頁相簿會依這組照片的**實際比例**（例如 2:3 直式）排列：桌面一次剛好 3 張、平板 2 張、手機 1 張，**邊緣不會出現被切到一半的照片**，每張都完整顯示、不裁切。
- 同一組裡有少數比例不同的照片（例如一張橫式），會**完整縮小置中**放進同樣大小的格子。
- 大圖檢視、Works 總覽代表圖、About 照片也都完整顯示。
- 只有**首頁**的主照片與精選照片會依設計稿裁切，可用 `home/info.txt` 的「對焦」調整保留的位置。

## 新增一組作品（例如在 Emotional 往下多加一列）

### ① 建立資料夾、放照片

在 VS Code 左側檔案總管，對 `public/images/works/emotional` 按右鍵 → **新增資料夾**，**直接用作品名稱命名**，例如 `晨光`或 `Morning Window`，把照片拖進去：

```
public/images/works/emotional/晨光/01.jpg
public/images/works/emotional/晨光/02.jpg
…
```

**照片放進去的那一刻，Emotional 頁最下面就會多出一組「晨光」**。資料夾名稱＝網站上的作品名稱，中文、英文、空白、大寫都可以（不能有 `#` 或 `%`）。

### ② 加上文字

`npm.cmd run dev` 開著的話，照片放進去後，資料夾裡會**自動出現 `info.txt`**（終端機也會顯示「📝 新作品已自動建立文字檔」）。
沒開 dev 的話，在終端機執行 `npm.cmd run photos` 也會建立。

> 資料夾裡要**先有照片**才會建立；已經有 `info.txt` 的資料夾不會被覆蓋。

打開 `info.txt`，填「模特」「IG」「日期」（「標題」留空即可）：

```
標題：

模特：Model Name

IG：@model_account

日期：2026/05

順序：4
```

存檔就完成了。也可以不跑工具，直接從別的作品資料夾複製一份 `info.txt` 過來改。

### ③ 推送上線

```bash
git add .
```
```bash
git commit -m "Add new series"
```
```bash
git push
```

> 分類頁大標下的介紹（例如 Emotional 的「Three stories, quietly told.」）不會自動改，多了一組作品時記得到 `works/emotional/info.txt` 修改「介紹」。

### 作品順序、隱藏、改名

| 想做什麼 | 怎麼做 |
| --- | --- |
| 調整前後順序 | 打開**分類資料夾**的 info.txt（例如 `works/emotional/info.txt`），在「作品順序」把作品資料夾名稱**上下搬動整行**。新增的作品沒寫進去會排在最後 |
| 換 Works 總覽的代表圖 | 同一個分類 info.txt 的「總覽封面」：`作品資料夾/照片檔名`，例如 `被遺忘之人/03` |
| 暫時隱藏一組作品 | 該作品 info.txt 的「顯示」改成 `否` |
| 改作品名稱 | **直接重新命名資料夾**（先把該資料夾的 info.txt 分頁存檔並關掉）。如果首頁精選、分類的「總覽封面」或「作品順序」有用到這組作品，要一起改 `home/info.txt` 的「連結」與分類 info.txt（`npm.cmd run photos` 會提醒你） |
| 刪除一組作品 | 刪除整個資料夾 |

## 放到首頁精選

打開 `public/images/home/info.txt`，找到要換的【精選 N】：

```
【精選 1】
照片：works/emotional/晨光/01.jpg
照片描述：Portrait by a bright window
對焦：上
編號：01
標題：Emotional
介紹：Soft light,
before the city wakes.
連結：emotional/晨光
顯示：是
```

- **照片**：可以填 home 資料夾裡的檔名（`featured-emotional.jpg`），也可以直接用作品照片的路徑（從 `works/` 開始寫）。
- **對焦**：首頁會裁切照片，`上`、`中`、`下` 或百分比決定保留哪裡，避免切到臉。
- **連結**：`emotional` 到分類頁頂端；`emotional/晨光`（分類/作品資料夾名稱）直接跳到那組作品。
- 想多放幾張：往下加【精選 6】【精選 7】…，每 5 張自動成一組新的交錯排版。

替換首頁主照片最簡單：用同檔名覆蓋 `public/images/home/hero.jpg`。

## 上線前檢查

```bash
npm.cmd run photos
```
會先自動縮小太大的照片，再列出每組作品的照片數，以及需要注意的地方：含 GPS、檔名大寫或空白、找不到的照片、info.txt 打錯的欄位（含第幾行）。

```bash
npm.cmd run build
```
建置前會自動檢查照片；有照片找不到時會停止，Vercel 也不會把壞掉的版本上線（舊版網站繼續運作）。

開發中也可以按 `F12 → Console`，查看「[內容檢查]」開頭的提醒。
