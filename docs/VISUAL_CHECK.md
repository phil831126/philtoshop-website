## 與附圖的已知差異

| 差異 | 原因／說明 |
| --- | --- |
| 照片全部為示意圖 | 未提供原始照片，見下方「待替換素材」。設計稿截圖沒有被裁切或冒充作品。 |
| 字型為替代字型 | 原稿字型未提供。標題用 **Source Serif 4**（襯線、SIL OFL 授權）、內文用 **Inter**（SIL OFL 授權），透過 npm 套件自架。附圖標題字的字腔略寬、筆畫對比略高，取得原字型後可在 `tokens.css` 替換。 |
| 分頁照片比例 | 相簿格子依每組照片的實際比例自動調整（2:3、9:16 皆可），桌面剛好 3 張、平板 2 張、手機 1 張，不露出半張照片；附圖手機版原本露出下一張的一小段，已依你的要求改為完整一張（可在 tokens.css 改回）。 |
| 首頁右上照片（Ordinary） | 附圖中沒有文字；依使用者要求改成和其他精選相同的「編號 / 標題＋介紹」，桌面版放在照片上方，手機版在照片下方。 |
| 頁尾 | 附圖未包含頁尾，採極簡設計（品牌名＋版權）。 |
| Works 總覽、About、404 | **延伸設計**：附圖未提供，沿用分頁的字級、細線與配色簡約處理。 |
| 照片數不足以捲動時 | 依附圖保留控制列與計數（例如 01 / 03），箭頭維持停用並淡化。 |
| 很長的單一英文字作品名 | 桌面左欄較窄（依附圖約 22.5%），超過約 9～10 個字母的單字在 1024～1100px 寬度可能被強制斷行（Windows 版 Chrome 不支援自動連字號）。建議作品名稱使用一般長度單字。 |
| 平板（768–1023px） | 相簿一次 2 張、左欄加寬到 30%；首頁精選改為兩欄交錯。 |
